# Documentacion

## UX y diseño

- **Prototipos (Figma):** [Discordia — Prototipos y sistema de diseño](https://www.figma.com/design/YV4I8KiDbfm8lBaauL7dx5)
  - [Ver el prototipo navegable](https://www.figma.com/proto/YV4I8KiDbfm8lBaauL7dx5?node-id=4-7&starting-point-node-id=4-7), con tres flujos: cliente web (ingresar → chat → llamada), app mobile (ingresar → canales → chat → miembros) y backoffice (usuarios → reportes → métricas).
- **Sistema de diseño:** [ux/sistema-de-diseno.md](ux/sistema-de-diseno.md): tokens de color, tipografía, forma y componentes, alineados con `tailwind.config.ts`.
- **Decisiones de UX:** [ux/decisiones-ux.md](ux/decisiones-ux.md): qué decidimos sobre cómo se ve y cómo se navega, y por qué.
